不需要。直接安装这里提供的新版本即可覆盖更新，保留原有记录。请使用同一来源的安装包。

以后会自动安装新版本吗？＋

App 会自动检查并提示新版本。点击「立即更新」后会下载安装包，最后由你在 Android 系统窗口确认安装。首次可能需要允许 Issue 安装应用。

网页下载和 App 内更新是同一个版本吗？＋

是的。两者使用同一份版本信息和安装包。新版本发布后，网页和 App 会一起获取更新。
