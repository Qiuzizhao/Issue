面向「个人 Issue 追踪」这一单一用途的界面重构方案。目标不是换一层皮，而是让 还剩什么、什么时候到期、属于哪个项目 三件事在 1 秒内被看见，并把「完成一项」这个动作做出反馈闭环。 稿内含设计方向、Token、逐屏视觉稿、组件库、动效与落地映射。

设计方向

先诊断现状，再给出主张

现状诊断
  • 信息密度均匀，没有优先级。卡片全是白底 + 阴影 + 12px 圆角，逾期项和无关项长得一样，列表一长就“糊”。
  • 时间不可读。09-17 14:00 这类绝对时间要用户自己换算今天 / 逾期。
  • 头部信息浪费。Header 组件实际没有渲染 subtitle，「N 项待处理」根本看不到。
  • 项目靠纯文字 Tab 切换。无选中指示、无计数、无项目色，多项目时不知道自己在哪里。
  • 三套色系混用。企微蓝 #EBF2FF 做表头、主题色（默认红 #E03131）做强调、又一套语义色，互相抢戏。
  • 完成感弱。仅打勾 + 划线，卡片仍留在同一列表，勾完即“消失无踪”。
  • 深色模式缺设计。userInterfaceStyle: automatic，但色值全部硬编码浅色。
  • 编辑能力被压缩。数据模型有日期 / 时间 / 地点 / 描述，编辑弹窗却只有一个标题输入框。
改版主张
  • 时间语义化。逾期 / 今天 / 计划 / 无期限四态，用色 + 相对文案（「逾期 2 天」「今天 14:00」）直接给结论，列表按时间分组。
  • 项目色锚点。每个项目分配一个色相，出现在 chip、卡片色条与详情页，跨屏可识别。
  • 降噪分层。平面卡（1px hairline，无阴影）承担列表；阴影只留给浮层，用分组标题制造节奏。
  • 状态可见。顶部换成左对齐大标题 + 概览条（待处理 / 逾期 / 今日完成环），Header 副标题真正生效。
  • 反馈闭环。勾选 → 环形扩散 + 音效 → 卡片折叠 → 顶部进度环前进 → 落入「已完成」分段。
  • 主题色只做交互强调。语义状态色固定不随主题漂移，保证「红 = 逾期」永远成立。

视觉基调

冷静的中性底

背景 #F5F6F8，表面纯白与 #F0F2F6 两级；用描边而不是阴影做分层。

一个强调色

默认墨蓝 #3B5BDB，工具感强、深色模式友好，仍可由用户在设置中更换。

语义四态

红 = 逾期、琥珀 = 今天、蓝灰 = 计划中、青绿 = 完成；不随主题色变化。

克制的字重

标题 640–700、正文 400–500，不再全篇粗体；数字统一等宽。
