# 安卓窄屏适配

参照 Booky 的 `plugins/with-android-display-density.js`，在 Issue 的 Application 和 Activity 使用相同的显示配置，通过 Expo 配置插件保留适配逻辑。

- 普通手机短边小于 390dp 时，适度降低应用显示密度，目标短边约 390dp，最多缩小约 18%。普通宽屏、平板和报告铰链传感器特征的折叠设备保持原显示密度。
- 使用整屏 `getRealMetrics`，避免按分屏窗口重复补偿；仅覆盖显示密度和字体缩放，保留窗口、方向、键盘等配置的动态变化。
- 应用字号缩放上限为 1，系统较小字号继续跟随；不修改系统显示或字号设置。原生输入框和对话框使用相同配置。
- Android 当前窗口宽度小于 400dp 或高度小于 700dp 时，采用紧凑页头、12dp 页面侧边距以及横向列表/看板切换按钮。
- 紧凑布局把编号移到标题下方，给长标题更多宽度；项目名和标签允许换行。添加按钮继续使用 80dp 大尺寸。
- 关闭状态的侧滑操作区透明，避免非整数显示密度下出现边缘细线。

## 验证

已通过 TypeScript、Expo lint、现有项目结构检查、3 项配置插件测试，以及本地 `:app:compileDebugKotlin` 编译。插件测试覆盖生命周期保留、重复运行和拒绝覆盖自定义上下文。

正式 APK 已于 1.0.11（17）构建发布，并完成模拟器同签名覆盖安装、320dp 窄屏启动及本地模式持久化检查，见 [发布记录](releases/1.0.11.md)。未进行安卓厂商真机验收。新配置在安装新版 APK 后生效。
